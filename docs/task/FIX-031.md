## Problem

Regression from FIX-028. Pinned top-N "common tags" no longer show 常驻 at
normal page width. The `ResizeObserver` measures the component's own `rowRef`
div, but that div is a shrinkable flex item (`flex min-w-0 flex-wrap`) sharing
the row with status chips and search. Measured width << real available width →
`pinnedFitCount` returns 0 → no pinned chips render.

## Scope

- `apps/web/src/app/routes/_app/projects/-project-tag-filter.tsx`
- `apps/web/src/app/routes/_app/projects/-project-tag-filter.fit.ts`
- `apps/web/src/app/routes/_app/projects/-project-tag-filter.fit.test.ts`
- `apps/web/src/app/routes/_app/projects/-project-tag-filter.test.tsx`

## Requirement

Common tags must reliably show inline (up to `PINNED_COUNT=5`) at normal desktop
widths; only shrink/drop pinned chips on genuine narrow/overflow, not from
mis-measuring a starved wrapper. Keep responsive shrink when truly narrow.
Verify pinned chips appear on projects home AND issues/procurement tabs.

## Acceptance

- Pinned chips render at normal width on all three lists.
- Responsive shrink preserved for genuinely narrow widths.
- `bun run check` green (web + api), no new failures.
