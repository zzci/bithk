## Description

Redesign the project issue (work order) detail surface toward the calm,
sectioned "zen" detail layout from the `backup/untitled` prototype
(`tab-workorders.jsx` `WoDrawer`). Because every place that opens an issue
already renders the single shared `ProjectIssuePanel`, redesigning that one
component applies the new look to both the drawer and the fullscreen page with
no duplicated edits.

Acceptance criteria:

1. The shared `ProjectIssuePanel` is restyled to a zen-mode layout: a clean
   header (status/priority chips + title + actions), a quiet meta strip
   (assignee / due date / creator / timestamps), a focused description block,
   and the existing comments + attachments footer — using only real issue
   fields, no invented data.
2. The fullscreen variant reads as a centered, distraction-free content column
   (constrained max width, generous spacing); the drawer variant keeps its
   narrower form. Both come from the same component.
3. All existing behavior is unchanged: inline title/description editing,
   status/priority/assignee/due-date editing, permissions, upload, delete
   confirmation, maximize/close, Escape handling, i18n keys, and routes.
4. No backend/API/schema changes; no new dependencies.
5. Focused tests and `bun run check` pass.
