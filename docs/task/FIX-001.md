## Description

Drive file preview 的代码/文本视图未铺满容器（CodeMirror 宿主无尺寸样式 + 预览区
统一 `p-4` 内边距导致四周留白），且编辑态用的是原始 `<textarea>`，与高亮预览不一致。

修复目标：

2. 统一 `text` 类（含纯文本）的预览与编辑均走 CodeMirror；仅 `markdown` 保留 Milkdown 特殊处理。
3. 编辑态用可编辑的 CodeMirror 替换 `<textarea>`，文法按文件名解析，主题与预览一致。

验收：`bun run check` 绿；预览/编辑铺满无留白；保存/取消流程不回归。
