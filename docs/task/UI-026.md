# UI-026 HR approvals/payroll page completeness + colleague salary fields

- Status: Completed
- Plan: [PLAN-086](../plan/PLAN-086.md)
- Owner: local-session
- Updated: 2026-06-16

## Goal

Surface the new HR backend (FEAT-036) on the web: a colleague salary section, a
fuller approvals page with timing columns and a detail view, and a payroll page
with a colleague filter, per-currency totals, and an admin-only one-click
generate action — with governance controls hidden for non-admins.

## Scope

### Colleague form (`-colleague-form-logic.ts`, `-colleague-panel.tsx`)

- New Salary section: 标准月薪 (`salaryAmount`) + 币种 (`salaryCurrency`). Blank
  fields submit as `null`; an existing amount renders as its string value.

### Approvals page (`-approvals-page.tsx`)

- 申请时间 / 裁决时间 columns (list is newest-first from the backend).
- Full detail view showing the request reason and the decision note.
- Textarea inputs for reason / decision note.
- Approve/reject controls hidden for non-admins.

### Payroll page (`-payroll-page.tsx`)

- Colleague filter.
- 发放时间 (paid-at) column.
- Per-currency net summary fed by `meta.totals`.
- Thousands-separated money via the new `formatMoney` helper
  (`shared/lib/format.ts`).
- Textarea notes.
- Admin-only 生成本月薪资 one-click generate button (calls
  `POST /hr/payroll/generate`); mark-paid and generate hidden for non-admins.

### Data + i18n

- `shared/lib/api/{hr.ts,hr-payroll.ts}`: salary fields + the generate call +
  `meta.totals`.
- `shared/lib/format.ts`: `formatMoney` (locale-aware, grouped, no fractions).
- `locales/{en,zh}/hr.json` extended.

## Acceptance

- Salary fields round-trip on create/edit; blank → `null`.
- Approvals page shows both timestamps and the full detail; payroll page shows
  the colleague filter, paid-at column, grouped money, and per-currency totals.
- Non-admins see no approve/reject, no mark-paid, and no generate button.
- `bun run check` EXIT 0.
