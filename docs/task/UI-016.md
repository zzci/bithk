## Goal

Redesign the project work-order tab into a compact status-grouped list that
removes top status filters and view switching while preserving search, create,
row navigation, pinning, and useful metadata.

## Scope

- `apps/web/src/app/routes/_app/projects/-project-issues-tab.tsx`
- `apps/web/src/app/routes/_app/projects/-project-issues-tab.test.tsx`
- Direct project work-order locale keys when labels need to change.

Out of scope: backend APIs, database schema, unrelated project tabs/pages,
global navigation labels, broad terminology rewrites, dependency changes, and
design-system rewrites.

## Acceptance

- The top status filter/switch controls are removed.
- The work-order tab renders separate compact status groups with visible counts.
- The toolbar keeps only search and a create action.
- Rows preserve open/view and pin interactions plus useful metadata.
- Mobile row layout wraps metadata without crowding or overlap.
- Focused tests and `bun run check` pass after integration.
