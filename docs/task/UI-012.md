# UI-012 Linear-style create project dialog

- Status: Done
- Plan: -
- Updated: 2026-05-27

## Goal

Rework the create-project dialog so it lists existing tags, drops manually-set
fields the backend already derives, and adopts a Linear-style compact layout.

## Scope

1. Tags: replace the free-text input in the create dialog with a multi-select
   combobox sourced from `useTags()`, still able to create a brand-new tag from
   the typed query. `availableTags` is passed in from the list page.
2. Remove the project code field (backend auto-generates `P-<shortId>`).
3. Remove the status selector (new projects are always `active`; the backend
   defaults it). Stop sending `code` / `status` from the create payload.
4. Linear-style layout: borderless large title input, borderless description,
   a bottom property row for tags, footer with Cancel / Create.

Edit form (`-project-settings-general.tsx`) and the shared `TagsInput` are
untouched.

- `-project-form-dialog.test.tsx` updated to the trimmed field set.
