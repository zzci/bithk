## Goal

Rework the shared priority visual into a **background-backed icon** — a small
rounded chip with a tinted background containing a lucide signal-bar icon — as
the single source of truth across the issues list, procurement list, and the
create-issue dialog picker. Replace the bare colored dot.

## Scope

- `apps/web/src/shared/components/priority-signal.tsx` (primary).
- Call-site layout tweaks ONLY if the larger chip breaks the existing grid/row
  alignment: `-project-issues-tab.tsx` (list render ~428, dialog picker
  ~625/632) and `-project-procurement-tab.tsx` (~253). Keep the exported
  component prop signatures stable so call sites otherwise need no change.
- Focused test for `priority-signal.tsx` if practical.

Out of scope: the create-dialog layout (FIX-017), any backend/enum change,
adding a selectable `none` priority, status-color files, other modules.

## Design

- Render each level as a rounded chip (~`size-5`) with a tinted background at
  ~10–15% token opacity and a lucide signal-bar icon (~`size-3`) in the solid
  token color. Pick one size and keep it consistent.
- Icons: `SignalLow` / `SignalMedium` / `SignalHigh` / `Signal` family; an
  absent/`none` value renders a neutral `Minus`/dash.
- Color scheme (medium and high MUST be clearly different):
  - urgent = destructive (red)
  - high = warning / yellow token
  - medium = info / blue token
  - low = muted (gray)
  - none = neutral dash
- Keep `aria-label`/`title` on `PrioritySignal`; keep `PriorityGlyph`
  `aria-hidden` (label text is adjacent in the dropdown).
- Keep `PRIORITY_META` (and any new icon map) **module-private** so the file
  stays `react-refresh`-safe — only the components are exported.
- The component may accept/handle a display-only `none` (dash) for robustness,
  but the data model stays the 4-level union; do NOT export a non-component.

## Acceptance

- Priority chip + signal icon renders identically in issues list, procurement
  list, and the create-dialog priority pill + dropdown items.
- medium (blue) and high (yellow) are visually unambiguous; low gray; urgent red.
- Accessibility preserved (label/title on the titled variant).
- `priority-signal.tsx` remains `react-refresh`-safe.
- No call-site behavior change; only layout-alignment tweaks if strictly needed.
- `bun run check` exits 0 (the `@milkdown/ctx` removeEventListener teardown in
  `-project-issue-panel.test.tsx` is a KNOWN FLAKE — grep to confirm before
  treating a test exit 1 as real; web tests pass 565/565 normally).
