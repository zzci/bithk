# FIX-002 Frontend quality remediation: a11y focus rings, effect warnings, oversized files

- **status**: done
- **priority**: P2
- **owner**: main
- **createdAt**: 2026-05-24

## Description

前端质量审核发现三类问题，本任务统一处理（研发阶段，接受破坏性更改）：

1. **A11y（WCAG 2.4.7，最高优先级）**：52 处原生 `<button>` 分布在 25 个文件，其中
   多数缺少 `focus-visible:` 焦点环，键盘用户看不到焦点位置。`Button` 组件自带焦点环，
   绕过它的原生按钮失去了该能力。
2. **effect 警告**：4 处 `react/set-state-in-effect`
   （`-drive-file-picker.tsx:72`、`-file-preview-dialog.tsx:542/546/589`）。
3. **超大文件**：`-drive-file-list-surface.tsx`（1830）、`admin/policies.lazy.tsx`（1026）、
   `-file-preview-dialog.tsx`（1023）超过 800 行上限。

## ActiveForm

分三阶段（文件重叠，不能同文件并行）：

- 阶段 1 a11y：对每个缺 `focus-visible:` 的原生 `<button>` 补统一焦点环类
  `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring`；
  **修正（按用户反馈）**：不补 `focus-visible` 保留原生，而是直接把全部业务原生
  `<button>`（52 处）替换为 shadcn `Button`（`ghost`/`link`/`default` + `xs`/`sm`/
  `icon-xs` 等），焦点环/a11y/disabled 由组件集中提供，消除手维护负担。整行可点击项
  用 `Button variant="ghost"` + `h-auto w-full justify-start font-normal`。仅保留
  `app-sidebar` 的 LogoToggle（sidebar-ring 覆盖型点击区，符合 shadcn sidebar 约定）
  与 vendor `ui/sidebar.tsx`。`*.test.tsx` 不计。
- 阶段 2 effect：改派生状态 / 条件化，消除 4 处 `set-state-in-effect`。
- 阶段 3 拆分：按职责拆分三个超大文件，三文件互不重叠可并行。
- 阶段 4 自封装审查（按用户复核）：封装应建立在 shadcn 原语之上而非重写/绕过。
  - 新增 `ui/alert.tsx`（cva default/destructive，base-nova 风格）。
  - 新增 `ui/alert-dialog.tsx`（基于 `@base-ui/react/alert-dialog`，`role="alertdialog"`、
    遮罩不误关、无角落 X）。
  - `error-banner` 由"手拼 destructive div"改为 `Alert variant="destructive"` 薄封装，
    保留 `message`/null-guard API，23 处调用不变。
  - `confirm-delete-dialog` 底层 `Dialog` → `alert-dialog`，13 处调用 API 不变；确认键保持
    普通 Button（不 auto-close，父组件 mutation 成功后再关）。
  - `centered-hint`/`input-group` 无对应原语或为合理组合，保留。
  - 同步两处删除确认测试 `findByRole("dialog")` → `alertdialog`（语义变更）。
  - 备注：`admin/-settings-shared.tsx` 有独立同名本地 `ErrorBanner`，不在本次范围。

- 阶段 5 回退过度转换（按用户反馈：移动端横向滚动条 + 导航字号变小）：
  `Button` base 含 `whitespace-nowrap`+`shrink-0`+固定字号，套到"整行项/导航/面包屑"上会让
  依赖 `min-w-0`/`truncate` 的行无法收缩（横向溢出）并改变字号。将这些**大面积行/导航/面包屑/
  全宽占位**改回原生 `<button>`（+ `focus-visible` 焦点环），紧凑动作/图标/chip 按钮保持 `Button`。
  涉及：drive 侧栏导航项与团队目录项、命令面板结果行、drive/document 预览行与面包屑、
  附件行、收件人候选行、文件列表面包屑、PDF 缩略图、entry-create 面包屑/文件夹行、
  文档搜索结果行、文档树节点选择行、置顶文档行、issue 空描述占位、成员搜索结果行。
  原则：Button 仅用于紧凑动作；行/导航用 `Link`(真实跳转) 或原生 button(onClick)。

验收：`bun run check` 绿（typecheck+lint+test+build 全过，321 web 测试通过）；
封装均建立在 shadcn 原语之上；行/导航不再被 Button 的 shrink-0/字号副作用影响；功能不回归。
