# FIX-064 - Direct upload presign/confirm requests hit /api/api/... (404)

- Status: Completed
- Plan: [PLAN-106](../plan/PLAN-106.md)
- Created: 2026-07-06

## Problem

`upload-queue.ts` `postJson` prepends `${BASE_PATH}/api` while both callers already pass
paths starting with `/api/...` → presign requests go to `/api/api/drive/files/presign-upload`
and 404. Direct upload (FEAT-044) therefore never worked outside tests; uploads error out
(no multipart fallback despite the comment claiming one).

## Fix

- `postJson` uses `${BASE_PATH}${path}` (callers keep the `/api/...` form used elsewhere
  in the file).
- Regression test asserting the exact URLs presign/confirm are posted to.
