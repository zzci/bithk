# FIX-058 - Drop the macOS CI matrix leg

- Status: Completed
- Plan: -
- Created: 2026-07-02

## Summary

The `check` job ran on `[ubuntu-latest, macos-latest]`. The macOS leg doubles the heaviest CI job
at ~10x runner billing while the app deploys exclusively to Linux (Docker/lode); the only
mac-specific consumer is local dev, which does not depend on CI. Identified by
AUDIT-20260702-architecture.md → D12; approved for removal on 2026-07-02.

## Change

- `.github/workflows/ci.yml`: `matrix.os` reduced to `[ubuntu-latest]`. The matrix structure and
  the `if: matrix.os == 'ubuntu-latest'` step guards are kept so a mac leg can be re-added by
  editing one line.
