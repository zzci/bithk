# UI-025: Align HR module header and tab nav with other modules

- Status: Completed
- Plan: -
- Owner: main session
- Created: 2026-06-11

## Problem

The HR module (`/hr`) looks different from the other top-level modules
(Contacts, Projects, Ships):

1. No module-level header. Contacts/Projects/Ships open with the shared
   `PageHeader` (bold `text-2xl` title + muted description); HR jumps straight
   into a tab bar, and each sub-page renders its own smaller `text-lg` heading,
   so the page top is inconsistent.
2. The HR tab bar uses the default `TabsList variant="line"` styling instead of
   the project detail page's underline tab-nav treatment (`h-auto gap-6
   text-base` list + muted/active trigger classes), so the tabs read as a
   secondary widget rather than the page's primary navigation.

## Goal

Make `/hr` open like the other modules: shared `PageHeader` ("人事"/"HR" +
description) at the top, followed by an underline tab nav styled exactly like
the project detail page (概览/工单/采购/文件 pattern), then the tab content.
Remove the now-redundant per-tab `h1` + description blocks from the three
sub-pages.

## Acceptance Criteria

- [ ] `/hr` layout renders `PageHeader` with an HR module title + description
      (new `hr:page.title` / `hr:page.description` keys, en/zh parity).
- [ ] HR tab nav uses the project-detail tab treatment: `TabsList
      variant="line" className="h-auto gap-6 overflow-x-auto text-base"` and
      the same muted/active trigger class as
      `projects/$projectId.lazy.tsx` (`TAB_TRIGGER_CLASS`).
- [ ] Colleagues / Approvals / Payroll pages no longer render their own
      `h1` + description header (tab labels carry the section name).
- [ ] Existing tab routing behavior unchanged (one route per tab, deep links
      and back/forward still resolve).
- [ ] Tests updated (`-hr-layout.test.tsx`, sub-page tests if they assert the
      removed headings); `bun run check` EXIT=0.
