## Goal

Redesign `ProjectTagFilter` from inline-fit preset chips + "More" overflow into
a single tag SELECTOR control listing ALL tags with checkable state, plus the
SELECTED tags rendered as removable chips (X to deselect) to the right.

## Scope

- `apps/web/src/app/routes/_app/projects/-project-tag-filter.tsx`
- `apps/web/src/app/routes/_app/projects/-project-tag-filter-logic.ts` (remove

Out of scope: the 3 consumers (issues tab, procurement tab, projects list
`index.lazy.tsx`) — their props must stay valid with NO edits.

- Single-select shows one removable chip.
- Inline-fit logic removed: `MAX_INLINE_CHIPS`, `computeVisibleTagCount`,
  `ResizeObserver`, the hidden measuring layer.
- Public props/signatures UNCHANGED (`tags`, `multiple`, `selectedTagIds`,
  `onToggle`, `selectedTagId`, `onSelect`); all 3 consumers compile untouched.
- `-project-tag-filter.test.tsx` updated to the new UI and green.
