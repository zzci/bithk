# UI-014 Left-nav project settings dialog + tag picker fixes

- Status: Done
- Plan: -
- Updated: 2026-05-28

## Goal

Reshape the project settings dialog to a left-navigation layout with a fixed
size (no resizing/jumping between sections), keeping the current shadcn style.
Fix the create-dialog tag picker so it stops showing "no tags" when tags exist
and supports clearer multi-select.

## Scope

- `-project-settings-dialog.tsx`: replace the top `Tabs` with a left vertical
  nav (`role="tablist"`/`role="tab"`) + a right pane. Fixed dialog height
  (`h-[min(34rem,90svh)]`, `sm:max-w-3xl`); the right pane scrolls internally so
  switching sections never resizes the modal. Sections (General / Members &
  roles / Categories) stay capability-gated; content unchanged.
- `-project-tags-combobox.tsx`: drop `ComboboxEmpty` (its `data-empty` state was
  always true because items are rendered as children without the `items` prop,
  so "no tags" showed even with matches) in favour of a manual empty state shown
  only when there are no matches and nothing to create. Show all matching
  suggestions (selected included, with the check indicator) for multi-select.

## Verification

- `bun run check` passes; settings-dialog and tag-combobox tests green.
