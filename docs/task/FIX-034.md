## Goal

On the projects list `ProjectsGrid` card, restore whole-card navigation:
clicking anywhere on the card (cover image, title, description, tag row) opens
the project detail via `openProject(project.id)`. Today only the title text
navigates — a regression from commit 078c687 (RA-016), which swapped the
native stretched-link `<button>` for a shadcn `<Button>` whose
`after:absolute after:inset-0` no longer covers the whole card.

## Scope

- EDIT (only this file): `apps/web/src/app/routes/_app/projects/index.lazy.tsx`
  — the `ProjectsGrid` card (~226-287).

Do NOT touch any other file. No i18n change is required if you reuse the
existing project name for the accessible label; if you add a new key, keep
en/zh parity.

## Requirements

Pick ONE clean approach (verify in the running dev app):
- **Option A**: revert the title click target to a native
  `<button type="button">` carrying the stretched
  `after:absolute after:inset-0 after:rounded-[inherit]` overlay (as
  pre-078c687), with focus-visible styling for a11y (visible focus ring).
- **Option B**: keep the title as plain text and add a dedicated full-card
  click overlay — a native `<button>` or TanStack Router `<Link>` positioned
  `absolute inset-0` over the card (below the Settings button's `z-10`), with an
  `aria-label` naming the project (e.g. the project name).

Hard constraints:
- The WHOLE card navigates on click: cover image, title, description, tag row.
- The Settings button still opens settings (stays `z-10`) and is NOT triggered
  by card clicks (clicks on it must not also navigate).
- Keyboard accessible: the navigation target is focusable, Enter activates, and
  shows a visible focus ring.
- No console errors. Do NOT rely on `after:absolute inset-0` applied to a
  shadcn `<Button>` (that is the broken state).
- Keep the diff minimal and localized to this card.

Note on shadcn-button preference: the global rule prefers shadcn `<Button>` over
hand-rolled native `<button>`. The stretched-link overlay is the documented
exception here (a shadcn Button breaks the `::after` stretch) — a native
`<button>`/`<Link>` carrying the `after:absolute inset-0` overlay is the correct
pattern. Add `focus-visible` ring styling for a11y parity.
