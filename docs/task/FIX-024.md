## Goal

Two small tweaks to `ProjectTagFilter`:

1. The selector trigger stays NEUTRAL (outline) regardless of how many tags are
   selected — never the filled `default`/`primary` highlighted variant.
2. The dropdown/combobox list excludes already-selected tags (only unselected
   tags listed); graceful empty state when none remain.
