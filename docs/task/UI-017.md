# UI-017 Simplify project overview metadata layout

- Status: Completed
- Plan: [PLAN-025](../plan/PLAN-025.md)
- Owner: L2 dispatch 22waq92o
- Updated: 2026-05-28

## Goal

Simplify the project overview tab so creator, last updated time, tags, and
description read as one unified project information section, without the
right-side work-order and procurement summary metrics.

## Scope

- `apps/web/src/app/routes/_app/projects/-project-overview-tab.tsx`
- `apps/web/src/app/routes/_app/projects/-project-overview-tab.test.tsx`
- Direct project overview locale copy only if the existing labels cannot cover
  the new layout.

Out of scope: backend APIs, database schema, unrelated project tabs/pages,
global tag semantics, work-order/procurement data behavior, dependency changes,
and broad design-system rewrites.

## Acceptance

- Creator, last updated time, tags, and description are rendered in one compact
  cohesive information block with responsive wrapping.
- The overview tab no longer renders the right-side work-order/procurement
  metric summary content.
- Latest work orders, latest procurements, pinned items, dialogs, permissions,
  and current data loading behavior are preserved unless directly affected by
  the layout change.
- Focused overview tab tests cover the unified information block and absence of
  summary metrics.
- Focused verification runs, and `bun run check` is attempted. If the only full
  gate failure is the known FEAT-015 API typecheck blocker, it is reported
  without modifying FEAT-015 code.
