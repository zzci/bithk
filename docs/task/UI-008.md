## Description

The ships, projects, and contacts modules carry a bespoke "prototype" visual
language (decorative ship illustrations, an extra `rounded-2xl bg-background`
page wrapper, and hand-rolled `bg-card` surfaces with `ring-foreground/5` /
`shadow-sm` that only approximate the real `<Card>` primitive). The rest of the
app (overview, documents, admin, drive) uses the standard shadcn base-nova
baseline. The three modules look like a different theme.

Normalize the three modules to the shared baseline. Development stage, breaking
changes accepted.

Acceptance criteria:

1. No page wraps its content in `rounded-2xl bg-background p-1 md:p-3`; pages
   rely on the `_app` `<main>` padding and use a `space-y-6` root.
2. `ShipIllustration` and `DetailShipIllustration` decorative graphics are
   removed.
3. Hand-rolled `bg-card` card/section/table surfaces use the real `<Card>`
   component (or a single canonical surface class) instead of bespoke
   `rounded-xl/2xl ... ring-foreground/5 ... shadow-sm` combinations.
4. The ships list card matches the projects list card pattern.
5. `bun run check` passes (lint, typecheck, tests, build) with affected module
   tests updated where selectors moved.
