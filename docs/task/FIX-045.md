# FIX-045 gen-api-docs omits ship/search/worklist routes

- Status: Completed
- Plan: -
- Owner: local-session
- Updated: 2026-06-16

## Goal

`apps/api/scripts/gen-api-docs.ts` builds the route index by mounting each
module's `*.routes` factory into a bare Hono app, but it never mounts
`shipRoutes`, `searchRoutes`, or `worklistRoutes`. So
`docs/reference/api-routes.md` (and `check:api-docs`, which compares against the
same generation) silently omitted every `/ships`, `/search`, and `/worklists`
route. Discovered while building FEAT-034. Mount the three missing routers so
the generated index covers the full protected surface.

## Scope

- `apps/api/scripts/gen-api-docs.ts`: import + `app.route("/", …)` for
  `shipRoutes`, `searchRoutes`, `worklistRoutes`.
- Regenerate `docs/reference/api-routes.md`.

## Acceptance

- `/ships*`, `/search`, `/worklists*` appear in `docs/reference/api-routes.md`.
- `bun run check:api-docs` passes against the regenerated file.
