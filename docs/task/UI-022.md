# UI-022: Project overview 2-column pinned/description + single-line pinned rows

## Problem

The project overview tab stacks the 描述 (description) and 置顶 (pinned) cards
full-width in a `space-y-6` column, while the latest-activity lists below use a
tidy 2-column grid of single-line rows. The pinned rows are two-line (title +
`Pin` icon, then a metadata line with kind badge, status badge, and `pinnedAt`
date), which reads heavier than the single-line `ActivityRow` items.

## Goal

1. Put the description and pinned cards side-by-side in a left-right 2-column
   row (description left, pinned right), mirroring the latest-activity grid.
2. Reduce each pinned row to one compact line (leading type icon + title +
   status badge), dropping the `pinnedAt` date and other secondary metadata.

## Acceptance Criteria

- [ ] Description + pinned cards render side-by-side in `grid gap-4
      lg:grid-cols-2` on `lg`, stacking to one column on small screens.
- [ ] The latest issues / procurements grid row below is unchanged.
- [ ] Each pinned row is a single horizontal line: leading type icon
      (`ClipboardList`/`Package`, `aria-hidden`) + truncated title + trailing
      status badge. No `pinnedAt` date, no kind text badge, no second line.
- [ ] Click-to-open navigation preserved (issue → issues, procurement →
      procurement; disabled when procurement not viewable).
- [ ] Now-unused `formatDate` import, `RowMeta` helper, and `ROW_BUTTON_CLASS`
      are removed; no other symbols left dangling.
- [ ] `-project-overview-tab.test.tsx` updated for the single-line pinned rows
      (kind-badge text assertions dropped) and still covers navigation + the
      2-col layout.
- [ ] `bun run check` EXIT=0 (only acceptable noise: the known @milkdown/ctx
      teardown flake — exit1 with 0 real test failures).
