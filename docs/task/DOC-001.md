# DOC-001 - ADR-014: HR module keeps flat module-gate RBAC

- Status: Completed
- Plan: [PLAN-105](../plan/PLAN-105.md)

## Summary

AUDIT-20260702-architecture.md flagged that HR is the only module using flat module-gate RBAC
(any global role containing the `hr` module can read all colleagues incl. salary and write
payroll amounts; only the `paid` transition is admin-gated), and asked for either an ADR or
row-level tightening. Decision (2026-07-04): keep the flat model, record it as deliberate.

## Acceptance Criteria

- `docs/decisions/014-hr-flat-module-gate-rbac.md` records context, decision, consequences,
  and the rejected row-level alternative with revisit triggers.
- No code/behavior change.
