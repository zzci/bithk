# UI-031 - Cover lightbox: floating close button, standard preview size, blank-area dismiss

- Status: Completed
- Plan: -
- Created: 2026-08-27

## Summary

The project-list and ship-list cover thumbnails open a lightbox (`CoverImage`
with `enableLightbox`). Its `DialogContent` is a fixed `max-w-[90vw]` box while
the image is centered inside it, so:

- the dialog close button sits on the 90vw box corner, far from the image;
- the transparent band beside the image belongs to the popup, so clicking that
  "blank" area does not dismiss (base-ui outside-press only fires on the backdrop);
- the enlarged image has no consistent size cap (90vw x 90vh).

Escape already closes (base-ui default, covered by an existing test).

## Acceptance Criteria

- The popup shrink-wraps the image so the close button floats on the image top-right corner.
- The close button stays legible over light photos (solid-ish background, not a bare ghost).
- Preview image size is standardized: capped at `80vh` height and `min(90vw, 64rem)` width,
  aspect ratio preserved, never upscaled past the box.
- Clicking the blank area outside the image (backdrop) closes the preview.
- Escape still closes the preview.
- Card thumbnails themselves stay unchanged (`h-28 w-full` on both lists).
- `bun run check` passes.
