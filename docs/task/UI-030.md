# UI-030 - Move Storage from standalone nav item into System Settings tab

- Status: Completed
- Plan: -
- Created: 2026-07-05

## Summary

Storage (`/admin/storage`) is currently a standalone admin nav item (order 45, right after
System Settings). It is platform configuration (upload driver, S3 credentials, server file
management) and belongs inside System Settings as a tab, matching the existing 8-tab layout
(auth / smtp / webhook / projectDefaults / general / ship / backup / about).

## Acceptance Criteria

- System Settings gains a `storage` tab (HardDrive icon) rendering the existing
  StorageConfigSection + StorageFilesSection with identical behavior.
- Standalone route `/admin/storage` and its nav item are removed
  (`storage.tsx`, `storage.lazy.tsx`, `-storage.nav.ts`, registry entry).
- i18n: storage keys live under `settings:storage.*`; `storage.json` namespace removed;
  `check:i18n` passes with no orphan keys.
- No backend changes (API endpoints under `shared/lib/api/storage.ts` untouched).
- `bun run check` passes.

## Files in Scope

- `apps/web/src/app/routes/_app/admin/settings.lazy.tsx`
- `apps/web/src/app/routes/_app/admin/-settings-storage.tsx` (new, from storage.lazy.tsx)
- `apps/web/src/app/routes/_app/admin/storage.tsx` / `storage.lazy.tsx` / `-storage.nav.ts` (delete)
- `apps/web/src/shared/components/sidebar/registry.ts`
- `apps/web/src/locales/{en,zh}/settings.json`, `apps/web/src/locales/{en,zh}/storage.json`
