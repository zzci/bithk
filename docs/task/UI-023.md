# UI-023: Project overview description+pinned grid 2:1 responsive ratio

- Owner: l1-75ymcfnr / L2 to81pc78
- Created: 2026-06-03

## Problem

The project overview tab places the description and pinned cards side-by-side in
`grid gap-4 lg:grid-cols-2` (equal 1:1 columns) on wide screens. The description
generally carries more content than the pinned list, so an even split wastes
width; the description deserves the wider column.

## Goal

Make the top description+pinned grid row responsive with a 2:1 ratio on wide
screens:

- small (base): single column, stacked.
- medium: 1:1 — two equal columns.
- large: 2:1 — description column twice the pinned column, via
  `lg:grid-cols-3` + description `lg:col-span-2` / pinned `lg:col-span-1`.

## Acceptance Criteria

- [ ] The top grid wrapper is `grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3`.
- [ ] The description card spans `lg:col-span-2`; the pinned card spans
      `lg:col-span-1` (description twice as wide as pinned on `lg`; equal on
      `md`; stacked on small).
- [ ] `ProjectInfoCard` and `ProjectPinnedCard` accept an optional `className`
      forwarded onto their `<Card>` via `cn(...)`.
- [ ] Card content, the pinned-row markup, and the latest issues/procurements
      grid row below are unchanged.
- [ ] `bun run check` EXIT=0 (lint+typecheck+test+build all green; only the
      known @milkdown flake is acceptable noise).
