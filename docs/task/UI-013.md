# UI-013 Fix and polish the Linear-style create-project dialog

- Status: Done
- Plan: -
- Updated: 2026-05-27

## Goal

The create-project dialog layout is broken: the shared `DialogFooter` bleeds
with `-mx-4 -mb-4` (it assumes the content has `p-4`) but the dialog used `p-0`,
so the footer escaped the rounded box, and a stray `Separator` doubled the
divider. Rebuild a clean Linear-style modal body.

## Scope

- `-project-form-dialog.tsx`: self-managed padding (no `p-4` reliance), an
  accessibility-only (sr-only) title, a borderless focal name input, a
  borderless description, a properties row, and a custom bordered footer (not
  the bleeding `DialogFooter`).
- `-project-tags-combobox.tsx`: reworked into a Linear-style property control —
  a dashed "Tags" pill that opens a popup with a search box (existing tags +
  inline create), with selected tags shown as removable chips.
- Description placeholder softened to "Add a description…" / "添加描述…".

## Verification

- `bun run check` passes; `-project-form-dialog.test.tsx` and the reworked
  `-project-tags-combobox.test.tsx` are green.
- The dialog renders as a tidy Linear-style modal (footer contained, single
  divider, dashed tag pill).
