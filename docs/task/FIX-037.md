## Goal

The project members "角色" (role) select renders two "项目所有者" entries because
the member settings file labels every system role as owner. The two system roles
(Owner `kind="owner"`, Guest `kind="guest"`) collapse to the same label. Switch
labelling on `role.kind` and drop the Guest role from the assignable dropdown.

## Changes

1. `apps/web/src/app/routes/_app/projects/-member-helpers.ts` — add an exported
   `systemRoleLabel(role, ownerLabel, guestLabel)` (move the existing
   implementation from `-project-settings-roles.tsx`): `kind==="guest"` →
   `guestLabel`; otherwise (`kind==="owner"` or legacy system role with no kind)
   → `ownerLabel`.
2. `apps/web/src/app/routes/_app/projects/-project-settings-roles.tsx` — import
   `systemRoleLabel` from `-member-helpers.ts`; delete the local copy
   (lines ~128-134). No behaviour change there.
3. `apps/web/src/app/routes/_app/projects/-project-settings-members.tsx`
   - `roleNames` map (~76): `role.isSystem ? systemRoleLabel(role,
     t("roles.owner"), t("roles.guest")) : role.name`.
   - `RoleSelect.roleLabel` (~415): same kind-based resolution for system roles.
   - In `RoleSelect`, filter the rendered options to exclude `kind==="guest"`
     (Guest is the delete-fallback role, not manually assignable). The trigger
     value resolution must still label a currently-selected guest role correctly
     (use the full `roles` list for label lookup, only the option list is
     filtered).
4. `apps/web/src/app/routes/_app/projects/-project-settings-members.test.tsx` —
   add/extend assertions: a Guest system role (`{kind:"guest", isSystem:true}`)
   shown in the member table renders as "Guest"; the assignable dropdown options
   do not include "Guest"; the existing "Project Owner" / "Worker" assertions
   still pass.

## Scope

- `apps/web/src/app/routes/_app/projects/-member-helpers.ts`
- `apps/web/src/app/routes/_app/projects/-project-settings-roles.tsx` (import + delete local copy only)

  (once), Reader, Commenter, Writer — no duplicate, no Guest option.
- A member on the Guest role still displays as 访客 / Guest in the table.
- `systemRoleLabel` is defined once (in `-member-helpers.ts`) and imported by
  both consumers.
- en/zh parity preserved (`roles.guest` already present in both).
