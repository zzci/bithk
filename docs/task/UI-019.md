- Updated: 2026-05-28

## Goal

Polish the project overview list sections so pinned items, latest work orders,
and latest procurements are clearer, lighter, more scannable, and consistent
with the recently simplified project overview metadata layout.

## Scope

- `apps/web/src/app/routes/_app/projects/-project-overview-tab.tsx`
- `apps/web/src/app/routes/_app/projects/-project-overview-tab.test.tsx`
- Direct project overview locale copy only if existing labels cannot cover
  improved loading or empty states.
- `docs/changelog.md`

Out of scope: backend APIs, schema, work-order tab refinement, issue detail
migration, global tags, right-side summary metrics, dependency upgrades, and
broad design-system changes.

## Acceptance

- Pinned items, latest work orders, and latest procurements have clearer row
  hierarchy, spacing, metadata alignment, and responsive wrapping.
- Loading and empty states for these lists read as intentional overview states
  instead of loose body text.
- The recently simplified metadata block remains intact except for tiny local
  spacing adjustments required for cohesion.
- Removed summary or metric cards are not reintroduced.
- Existing data hooks, permissions, pinned behavior, tab navigation, latest
  work-order links, latest procurement links, and interactions are preserved.
- Focused tests cover list rendering, empty states, and interactions affected
  by the polish.
- Focused verification runs, and `bun run check` is attempted. If unrelated
  active campaigns cause failures, they are reported without fixing unrelated
  code.
