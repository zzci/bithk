# FEAT-021 - Finance colleagues module

- Status: Planned

- Campaign: local
- Owner: (unassigned)
- Created: 2026-06-09

## Summary

Add a Finance-owned colleagues module. A colleague is an internal finance actor
and must be linked to exactly one existing `users` row. The linked user may be a
real login user or a virtual user (`users.isVirtual = true`).

## Acceptance Criteria

- Finance has a colleagues API surface with list, create, update, and archive
  or delete behavior defined by [PLAN-073](../plan/PLAN-073.md).
- Each colleague row requires `userId -> users.id`.
- The module can select active real and virtual users from the existing
  assignable-user source.
- The web app exposes a Finance colleagues page or section using the existing
  React, TanStack Query, and shadcn/ui patterns.
- Focused API and frontend tests cover user-link validation and basic CRUD.
- `bun run check` passes after implementation.
