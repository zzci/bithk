# UI-011 Trim project module UI duplication

- Status: Done
- Plan: -
- Updated: 2026-05-27

## Goal

Remove redundant, backend-unbacked, or duplicated UI in the project module and
add a settings entry point from the project list.

## Scope

1. Project list card: drop the duplicate status/updated grid block (already shown
   by the header badge and the date line).
2. Add a project settings entry on the project list cards (admin only) that opens
   the project and its settings dialog via a `settings` search param.
3. Project detail overview tab: remove the key-information card and the tags card
   that duplicate the detail header; keep description, category preview, members.
4. Work order tab: remove the status summary StatStrip that duplicates the status
   filter chips below it.

- `bun run check` passes (lint + typecheck + tests).
