## Acceptance

- `PINNED_COUNT = 5` constant; `pinned = tags.slice(0, N)`, `rest = tags.slice(N)`.
- Pinned chips: `Button` per pinned tag with `aria-pressed={isActive}`, active
  style when selected, neutral otherwise; no × on pinned. Always rendered.
- Multi-select: pinned chip click → `onToggle(id)`; dropdown lists
  `rest.filter(!selected)`; non-pinned selected → removable chips via existing
  `RemovableChip` (× → `onToggle`).
- Single-select: pinned chip click when inactive → `onSelect(id)`; when active →
  `onClear()`; dropdown lists `rest.filter(id !== selectedTagId)` and
  `onSelect`; non-pinned selected → removable chip (× → `onClear`). When the
  selected tag is pinned, show only its active pinned chip (no removable chip).
- Dropdown/combobox trigger never renders the filled `primary` variant.
- Edge `tags.length <= N` → all pinned, dropdown hidden (or empty state); still
  renders pinned chips.
- Public props/signatures UNCHANGED; all 3 consumers compile untouched.
- New i18n key (e.g. `list.tagFilterPinLabel` = "Filter by {{name}}" /
  "按 {{name}} 筛选") for the pinned-chip aria-label; en/zh parity.
- `-project-tag-filter.test.tsx` updated: pinned chips rendered with
  aria-pressed + toggle; dropdown excludes pinned + selected; non-pinned
