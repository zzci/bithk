## Goal

Create a generic, reusable unified filter component and adopt it on the projects
list, replacing the pinned-tag ProjectTagFilter + separate status chips. Fixes
the pinned-chip flicker / 非常驻 bug architecturally (no ResizeObserver pinned-fit
on this path).

## Requirements

Generic component API (discriminated union on mode) WITH declarative residency:
```
interface FilterOption { value: string; label: string; count?: number }
type FilterDimension =
  ( { mode: "single"; value: string | null; onChange: (v: string | null) => void; defaultValue?: string }
  | { mode: "multi"; value: string[]; onChange: (v: string[]) => void } )
  & { key: string; label: string; options: FilterOption[];
      resident?: boolean;        // whole group rendered inline as always-visible toggle chips
      residentCount?: number }   // first N options inline as toggle chips; remainder in dropdown
interface ListFilterProps { dimensions: FilterDimension[]; className?: string }
```
- RESIDENT (常驻) items render INLINE outside the dropdown as always-visible
  toggle chips: click to filter, highlighted when active (aria-pressed), ALWAYS
  shown, NO ResizeObserver / NO width-fit math (never flicker), NO × (highlight
  conveys state). `resident:true` = whole group inline; `residentCount:N` =
  first N options inline, the rest go to the dropdown.
- Single 筛选 trigger Button → dropdown (use existing
  `@/shared/components/ui/dropdown-menu`) listing only the NON-resident remainder,
  grouped by dimension with section labels, aria-checked items, optional counts.
  Hide the trigger if no remainder exists.
- Selecting a NON-resident option → removable × chip to the RIGHT (real Button
  remove, aria-label). a11y: trigger Button, chip remove Button + aria-label,
  resident toggles aria-pressed, dropdown items aria-checked.
- Do NOT reintroduce `-project-tag-filter.fit.ts` or any width measurement.

Projects-list adoption (index.lazy.tsx, current filter row ~105-153):
- 状态 dimension: single, `resident: true` (whole group inline toggle chips),
  options active/archived (labels `status.active`/`status.archived`) with counts
  (activeCount/archivedCount), default `__active__`. Wire to existing `filter`
  state + `setPage(1)`.
- 标签 dimension: `residentCount: 5` (top-5 most-used tags pinned inline as
  toggle chips, always shown; the rest in the 筛选 dropdown). SINGLE-select to
  match today (`filter` holds a tagId; status and tag mutually exclusive).
  Selecting a resident tag highlights it; a non-resident tag chosen from the
  dropdown shows as a removable × chip. Keep IDENTICAL list results via
  `projectsFilterToQuery` (do NOT change its semantics).
- Keep the search box unchanged.

i18n: add `筛选`/`Filter` trigger label + dimension section labels (reuse
`status` and `list.tagFilterMore="Tags"`/标签 where possible). en + zh parity.
